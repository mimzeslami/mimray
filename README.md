# mimray community servers (data branch)

`community/servers.json` lists servers donated by users. The mimray app shows them under
**Free → Shared by the community**.

Don't edit this branch by hand. Entries are added and removed by the `community` workflow
on `main`, when a maintainer labels a "Share a server" issue `approved` or `remove`.
To share a server, open an issue with the **Share a server** form.
